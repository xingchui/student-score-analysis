# 学生成绩分析系统 (Streamlit版)

## 简介

这是一个**完全自动化**的学生成绩分析系统，无需手动操作DataEase。只需上传Excel文件，系统会自动：
- 合并处理多个考试数据
- 生成交互式分析仪表板
- 分析进步/退步趋势
- 支持数据导出

## 功能特性

- 📤 **一键上传** - 支持批量上传多个Excel文件
- 📊 **自动分析** - 智能识别列，自动合并数据
- 📈 **丰富图表** - 科目对比、班级对比、趋势图、分布图
- 👨‍🎓 **学生追踪** - 个人成绩趋势、排名变化
- 📉 **进步分析** - 自动计算进步/退步排名
- 📥 **数据导出** - 支持CSV导出

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行应用

```bash
streamlit run student_analysis_app.py
```

应用将在浏览器中打开（默认地址：http://localhost:8501）

### 3. 使用方法

1. 在侧边栏上传Excel文件（可多选）
2. 设置分析选项（优秀分数线、Top数量）
3. 查看各个分析标签页：
   - **总体概览** - 科目统计、分数分布、优秀率
   - **班级分析** - 班级对比、班级详细数据
   - **学生详情** - 个人成绩趋势、历史成绩
   - **进步分析** - 进步/退步排行榜
   - **数据报表** - 导出各类报表

## 技术栈

- **Streamlit** - Web应用框架
- **Pandas** - 数据处理
- **Plotly** - 交互式图表

## 注意事项

1. 学号是学生唯一标识，用于追踪进步/退步
2. 上传多次考试数据才能分析进步趋势
3. 桌面版使用，无需联网
