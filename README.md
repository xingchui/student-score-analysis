# 学生成绩分析系统

## 简介

这是一个基于 **Streamlit** 构建的自动化学生成绩分析系统，专为学校、教师和学生设计。只需上传 Excel 成绩文件，系统会自动生成交互式分析仪表板，无需手动操作 DataEase 或其他工具。

---

## 功能特性

| 功能 | 说明 |
|------|------|
| 📤 批量上传 | 支持同时上传多个 Excel 文件 |
| 📊 智能识别 | 自动识别各种列名格式 |
| 📈 科目统计 | 语文/数学/英语/选考科目分析 |
| 🏫 班级对比 | 班级平均分、上线人数对比 |
| 👨‍🎓 学生追踪 | 个人成绩趋势、排名变化 |
| 📉 进步分析 | 进步/退步排行榜（可配置阈值） |
| 📥 数据导出 | 支持 CSV 格式导出 |

## 快速开始

### 方式一：双击运行（推荐）

```
1. 复制以下文件到目标电脑：
   - student_analysis_app.py
   - 启动学生成绩分析系统.bat
   
2. 双击 "启动学生成绩分析系统.bat"

3. 浏览器自动打开 http://localhost:8501
```

### 方式二：手动运行

```bash
# 1. 安装 Python（如果没有）
# 下载地址: https://www.python.org/downloads/

# 2. 安装依赖
pip install streamlit pandas numpy plotly openpyxl

# 3. 运行应用
streamlit run student_analysis_app.py

# 4. 浏览器访问 http://localhost:8501
```

### 方式三：Git 克隆

```bash
# 1. 克隆仓库
git clone https://github.com/xingchui/student-score-analysis

# 2. 进入目录
cd student-score-analysis

# 3. 安装依赖
pip install -r requirements.txt

# 4. 运行
streamlit run student_analysis_app.py
```

## 使用指南

### 1. 数据上传

两种方式：
- **文件夹路径**：输入包含 Excel 文件的文件夹路径
- **点击上传**：直接点击上传按钮选择文件

### 2. 分析配置

在侧边栏设置：
- **总分分数线**：985线 / 211线 / 一本线
- **单科分数线**：可单独设置各科目分数线
- **进步/退步阈值**：分数变化超过此值才标记为进步/退步

### 3. 分析标签页

| 标签页 | 内容 |
|--------|------|
| 📈 总体概览 | 科目统计、分数分布、优秀率热力图 |
| 🏫 班级分析 | 班级对比、班级详细数据、各科平均分 |
| 👨‍🎓 学生详情 | 个人成绩趋势、历史成绩查询 |
| 📊 进步分析 | 进步/退步排行榜、排名变化 |
| 📋 数据报表 | 导出班级/学生/科目/进步分析报表 |

## 故障排除

### 问题：双击 bat 文件无法运行

**解决方法**：
1. 检查 Python 是否已安装：`win + R` → 输入 `cmd` → 输入 `python --version`
2. 如未安装，下载安装 Python：https://www.python.org/downloads/
3. 安装时勾选 "Add Python to PATH"

### 问题：浏览器显示 "Cannot connect"

**解决方法**：
1. 检查命令提示符窗口是否保持打开
2. 确认显示 "Running on http://localhost:8501"
3. 尝试访问 http://127.0.0.1:8501

### 问题：依赖安装失败

**解决方法**：
```bash
# 升级 pip
python -m pip install --upgrade pip

# 单独安装每个依赖
pip install streamlit
pip install pandas
pip install numpy
pip install plotly
pip install openpyxl
```

### 问题：Excel 文件读取错误

**检查项**：
1. 文件格式是否为 .xlsx 或 .xls
2. 文件是否被其他程序打开
3. 第一行是否为表头
4. 学号列是否唯一
